# Dataset

Download the labeled training files from the [IEEE-CIS Fraud Detection competition on Kaggle](https://www.kaggle.com/competitions/ieee-fraud-detection/data) and place them in this folder:

- `train_transaction.csv`
- `train_identity.csv`

Run [the analysis notebook](../Python/01_data_audit.ipynb) to generate `fraud_analysis_powerbi.csv` in this folder. Git tracks this setup guide and ignores the data files.
